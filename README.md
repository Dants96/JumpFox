
# JumpFox

JumpFox es un pequeño juego de plataformas desarrollado en C#. El objetivo principal del proyecto fue crear un videojuego simple utilizando exclusivamente **assets libres**.

## Características

- Juego de plataformas clásico.
- Todos los gráficos, sonidos y recursos utilizados son libres.
- Código fuente escrito 100% en C#.

## Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Dants96/JumpFox.git
   ```
2. Abre el proyecto en tu entorno de desarrollo compatible con C# (por ejemplo, Visual Studio).
3. Compila y ejecuta el proyecto.

## Créditos

- Este juego utiliza assets libres provenientes de diferentes fuentes. Consulta la carpeta `assets` para más detalles y créditos específicos.

## Objetivo

El propósito de JumpFox es servir como ejemplo práctico para aprender sobre desarrollo de videojuegos en C#, así como promover el uso de recursos libres en proyectos personales y educativos.
